# Squad content policy (superseded)

MLS `admin_pubkeys` flags for who may add events and docs are gone. Settings has no Access mode.

Create and add use SquadAdmin packed flags `createEvent` and `addDoc`. See [`../governance/ACCESS_CONTROL.md`](../governance/ACCESS_CONTROL.md). Incoming `pacto_squad_content_policy` rumors are dropped. The `squad_content_policy` table is dropped.

Update and remove of another member’s event or doc stay with the author or an MLS admin.
