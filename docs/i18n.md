# Internationalization (i18n)

User-facing copy lives in `src/lib/i18n/locales/{en,es}/*.json`. Namespace prefix matches the file name (`messaging.json` → `messaging.*`). English and Spanish catalogs must stay at exact key parity; ICU variable names must match across locales (they are identifiers, not translated words).

## Guards

- `@intlify/svelte/no-raw-text` (warn) catches hardcoded text nodes in `.svelte` templates.
- `src/lib/i18n/messages.test.ts` enforces en/es key parity and ICU variable parity.
- `pnpm check:i18n-toasts` fails on string literals that bypass catalogs in app source (TS modules and scripts that the raw-text rule cannot see):
  - `showToast('…')`
  - `confirm('…')` / `alert('…')` (and `window.*`)
  - non-empty `getInvokeErrorMessage(e, '…')` fallbacks (pass `get(t)('…')`; empty `''` is allowed for marker matching)

Resolve toast and fallback copy with `get(t)('…')` at call time.

## Squad in Spanish: `escuad` / `escuads`

Spanish catalogs use **escuad** (plural **escuads**) for the product term **Squad**, not dictionary **escuadrón** / **escuadrones**.

That slang is intentional. It is improper Spanish; we prefer it because it tracks the English product word and stays short in UI chrome. Do not “correct” catalogs back to escuadrón.

## Intentional English exceptions (audit closed)

After the #284 slices (#426, #442, #444, and the executor-roles / scaffold follow-up), remaining English in app source is intentional. Do not migrate these without a new product decision:

| Kind | Examples | Why left |
|------|----------|----------|
| Browser-preview gates | `… only available in the desktop app` in wallet / allowlist / pricing / username helpers | Never shown in the Tauri app |
| Canonical executor-role tokens | `formatSquadAdminExecutorRoles` → `Full`, `Paused`, `(paused)` | Stable map/cache/rights identifiers; UI uses `localizeSquadAdminExecutorRolesLabel` |
| Hat / role lookup keys | `Captain`, `Squad Admin`, `Mutiny Role`, … in payload builders | Matched as keys; display already goes through i18n |
| Backend / migration markers | `localizeRoleLabel` / `localizeAclReason` inputs, `MIGRATION_GATE_MESSAGE` | Must match backend or gate strings exactly |
| Design playground | Sketch theme labels under `src/routes/design/` | Dev-only; not shipped chrome |
| Wire / broadcast content | `defaultPublicSquadBroadcastMessage` | Published content other clients see; keep canonical |
| Network / asset proper nouns | Display names in `wallet-assets.json` | Proper nouns |
| Locale endonyms | `English` / `Español` in the language picker | Endonyms stay untranslated |
| Backend `e.message` / `out.message` pass-through | Toasts that surface invoke errors | Needs a code→key map policy, not a literal ban |

New user-facing copy must still go through en + es catalogs. Extend `pnpm check:i18n-toasts` when adding another high-traffic literal escape hatch.
