# Internationalization (i18n)

User-facing copy lives in `src/lib/i18n/locales/{en,es}/*.json`. Namespace prefix matches the file name (`messaging.json` → `messaging.*`). English and Spanish catalogs must stay at exact key parity; ICU variable names must match across locales (they are identifiers, not translated words).

## Guards

- `@intlify/svelte/no-raw-text` (warn) catches hardcoded text nodes in `.svelte` templates.
- `src/lib/i18n/messages.test.ts` enforces en/es key parity and ICU variable parity.
- `pnpm check:i18n-toasts` fails on `showToast('…')` string literals in app source (TS modules and scripts that the raw-text rule cannot see). Resolve toast copy with `get(t)('…')` at call time.

## Squad in Spanish: `escuad` / `escuads`

Spanish catalogs use **escuad** (plural **escuads**) for the product term **Squad**, not dictionary **escuadrón** / **escuadrones**.

That slang is intentional. It is improper Spanish; we prefer it because it tracks the English product word and stays short in UI chrome. Do not “correct” catalogs back to escuadrón.
